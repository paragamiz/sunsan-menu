เกี่ยวกับ wordmark (06, 07):
─────────────────────────────
• ตัว "u" เป็นสีอำพันโดดเด่นทุกแบบ
• ฟอนต์: Fredoka (rounded sans-serif) — เรียบ มินิมอล น่ารักสไตล์ญี่ปุ่น
• 3 layouts:
   - TH stacked  → sunsan ด้านบน, ซันซัง ด้านล่าง (default)
   - EN only     → sunsan อย่างเดียว (ขนาดเล็ก / ป้ายภาษาเดียว)
   - Inline      → sunsan · ซันซัง แนวนอน (เหมาะกับ header เว็บ / นามบัตร)


6 สี (ทั้ง wordmark และโลโก้เต็ม):
─────────────────────────────────
• ink              — กรมท่าบนพื้นใส (ใช้ได้ทุกที่)
• on-yellow        — บนพื้นเหลือง
• on-blue          — บนพื้นฟ้า
• on-cream         — บนพื้นครีม
• reversed-on-ink  — บนพื้นกรมท่า, ตัวอักษรครีม + "u" เหลือง
• yellow-on-ink    — บนพื้นกรมท่า, ตัวอักษรเหลือง + "u" ครีม


SVG vs PNG:
─────────────
• SVG (06): ใช้ที่เว็บ, Figma, Canva, Illustrator → ขยายได้ไม่จำกัด เส้นเรียบเสมอ
• PNG (07): ใช้ที่ Word, PowerPoint, social media → ~1800 px
